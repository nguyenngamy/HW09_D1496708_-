
## 個人問題回答

### 1. 為什麼這題需要同時用到 `str`、`list`、`set`、`tuple` 和 `dict`？
原始名單是一段字串（`str`），先去空白、轉小寫並拆成 `list` 才能保留原本的報名順序與重複紀錄。轉成 `set` 是為了快速去重，再用交集、聯集、差集找出哪些人去兩場、哪些人只去一場。活動名稱固定不會改所以用 `tuple` 存起來；最後用 `dict` 整理人數跟應收金額，查費用和讀數值都比較清楚。

### 2. 寫這支程式時，你覺得最容易算錯或搞混的地方是什麼？
最容易搞混的是「總不重複人數」跟「報名人次」，還有算錢時一定要用各場去重後的人數乘單價，不能直接拿還沒去重的串列長度去算。另外，遇到測試三的空名單時，如果直接對空字串做 `split(",")` 會變成 `[""]` 而不是空串列 `[]`，所以要先判斷是不是空字串再拆開，人數和金額才不會算錯。
