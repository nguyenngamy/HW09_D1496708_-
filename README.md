# HW09 | Python 資料型別上機實作：兩場活動報名整理器

## 個人問題回答

### 1. 為什麼這題需要同時用到 `str`、`list`、`set`、`tuple` 和 `dict`？
一開始拿到的報名名單是文字（`str`），先去掉空白跟轉小寫，再用逗號拆成 `list`，這樣還看得出原本的報名順序跟重複的人。後面轉成 `set` 是因為要去重跟做集合比對（交集、聯集、差集），看誰兩場都去、誰只去一場會比較快。活動名稱是固定的所以用 `tuple` ，最後用 `dict` 把人數跟算好的費用收在一起，要查單價或讀數值時也比較不容易亂。

### 2. 寫這支程式時，你覺得最容易算錯或搞混的地方是什麼？
我覺得最容易搞混的是「總不重複人數」跟「報名人次」，還有算錢時一定要用各場去重後的人數去乘單價，不能直接用還沒去重的串列長度算。另外，測試三遇到空名單時，如果直接對空字串 `split(",")` 會變成 `[""]` 而不是空串列 `[]`，所以要先判斷是不是空字串再拆，不然人數跟金額都會跟著算錯。
